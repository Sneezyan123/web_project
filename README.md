# U2U (Ukrainians to Ukrainians)

Мобільний веб-додаток для пошуку та збереження україномовних YouTube-каналів.

## Локальний запуск

```bash
npm install
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000).

## Змінні середовища

- `MONGODB_URI`, `MONGODB_DB`
- `AUTH_SECRET`
- `YOUTUBE_API_KEY`
- `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`
- `FACEBOOK_CLIENT_ID`, `FACEBOOK_CLIENT_SECRET`
- `APP_URL` або `NEXT_PUBLIC_APP_URL`

## Скрипти

- `npm run dev` — режим розробки
- `npm run build` — production-збірка
- `npm run start` — запуск зібраного додатку
- `npm run lint` — перевірка ESLint
